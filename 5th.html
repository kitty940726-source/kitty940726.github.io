網頁專案製作學習心得

在這次的高雄市建築地標與空間美學個人網站開發過程中，我實踐了前端開發的核心觀念。從最基礎的 HTML5 標籤結構規劃開始，到如何運用 HTML 插入圖片、設計超連結與美化背景，都是非常扎實的體驗。

特別是在將專業知識（如建築地標的不規則結構、室內裝修的管線整合與軟裝美學）轉化為網頁內容的過程中，我發現網頁設計與空間設計有許多相通之處——兩者都極度重視「結構的穩固」與「使用者體驗的流暢度」。

最後，透過將程式碼推送至 GitHub 平台並成功啟用 GitHub Pages 網址，完成了從在地美學內容端到雲端部署的完整流程。這項技能讓我未來能更靈活地展示個人專業作品集！
